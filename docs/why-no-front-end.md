# Why this has no front end

The weekly job is to reconcile source costs, refresh usage weights, explain departmental shares and obtain review. A database and an agent can perform those jobs directly. Read-only branded HTML gives department owners a view they can open or print.

The base has no live browser forms, mobile data entry, offline synchronisation, drag-and-drop cost modelling, sign-in service or real-time collaboration. Local embedded use works without a database server after installation; it is not a multi-device offline application. Shared use needs a managed database and access controls.

Apptio has a broader hierarchy, reporting and integration platform. This base uses one allocation layer from services to departments. If those broader capabilities matter, Enterprise DNA scopes them for a customised version. Do not call the free base a complete replacement for every Apptio deployment.

Omni by Enterprise DNA builds and runs the version the business needs, for a setup fee then a retainer.
