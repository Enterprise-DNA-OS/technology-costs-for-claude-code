# Target research: IBM Apptio Costing

Checked 2 November 2026. Family: technology-cost-allocation. This is shared technology cost allocation into departments, distinct from the existing cloud-cost monitoring, software licence inventory, spend analysis and financial planning builds. The registry contained no Apptio or Serviceware target at selection.

## Annual bill first

IBM Software's own [AWS Marketplace pricing listing](https://aws.amazon.com/marketplace/pp/prodview-mdyxbluvzbcn4) lists Costing Standard at US$110,040 and Essentials at US$80,040 for a 12-month contract. These are public contract prices, not a verified NZ or AU small-business invoice. The listing prices a bounded technology-spend tier with additional fees beyond it. Private offers can differ.

The local customer material searched did not confirm Apptio use. Live CRM was not read. Do not imply a customer pays these amounts. Large enterprise buyers are an imperfect fit for the core owner-led customer base, reflected in the buyer score.

## Primary sources

- [IBM Costing product and editions](https://www.apptio.com/products/ibm-apptio/costing/): Costing Essentials, Standard and a Planning bundle. Supports allocation, financial and operational data, service cost understanding.
- [IBM's CSV export instructions](https://www.ibm.com/docs/en/apptio-platform/apptio-bi/saas?topic=reports-export-data): role permission, visualization export, filters preserved and column totals excluded. Report fields are configurable, so import uses explicit column mapping.
- [Serviceware for IT controllers](https://serviceware-se.com/en/solutions/it-financial-management/it-controller): allocation and reconciliation workflows, used as category evidence only.
- [Compusense FAQ](https://compusense.com/resources/faqs): analyst-based licensing and personalised quotes.
- [ReferralMD pricing](https://referralmd.com/pricing/): free core platform and paid usage services, so older directory pricing is not reliable selection evidence.

## Claim boundaries

A focused one-stage allocation base is feasible in one session. A full Apptio clone is not the claim. No benchmark data, inherited certification, automatic ledger posting or vendor feature impossibility is claimed. The ten demo questions show what this implementation answers; they do not establish that Apptio cannot answer them.
